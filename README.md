# Мои путешествия

Сайт живёт здесь: **https://gregory-gittools.github.io/travel-globe/**

Сайт с интерактивным 3D-глобусом: на нём точками отмечены города, куда вы
ездили, каждая точка — это фото. Клик по фото на глобусе, по дню в
календаре или по альбому в списке открывает окно с заметкой о поездке
и галереей. Клик по фото в галерее открывает его крупно вместе с
подписью, если она есть.

Кнопки «📍 Сегодня», «📅 Календарь» и «📁 Альбомы» в правом верхнем углу:

- «📍 Сегодня» сразу открывает календарь на текущем месяце.
- «Календарь» — месяц с подсвеченными днями поездок; стрелками
  листаете месяцы (или годы — в режиме «Год целиком») вперёд-назад,
  а списками месяца и года рядом с ними можно сразу перейти к нужному.
  Кнопка «Год целиком» показывает сразу все 12 месяцев года — клик по
  названию месяца открывает его отдельно.
- «Альбомы» — список поездок с поиском: текстовое поле ищет по
  названию/городу, поле даты показывает только поездки, идущие в этот
  день, кнопка × сбрасывает оба фильтра.

Оба окна закрываются кнопкой ×, кликом мимо окна или клавишей Esc.

### Что умеет страница поездки

- 🔊 — прочитать описание поездки вслух (голос браузера).
- «Запрос Gemini» — открывает Gemini с уже готовым вопросом о поездке
  (текст также копируется в буфер обмена — если Gemini не подставит
  его сам, можно вставить вручную). Такая же кнопка есть и в
  полноэкранном просмотре фото — там вопрос собирается уже про
  конкретное фото (со ссылкой на него и подписью, если есть).
- В полноэкранном просмотре фото: стрелки «назад/вперёд», колесо мыши
  и клавиши ←/→ листают фото, кнопка «Слайдшоу» включает автопоказ.
  Двойной клик по фото — переход в полноэкранный режим браузера;
  запуск слайдшоу тоже включает полноэкранный режим автоматически.
- 🎵 «Музыка» (кнопка появляется, только если для поездки указана
  музыка) — включает/выключает фоновый трек во время просмотра фото.
- «Показать альбом на карте» — открывает карту со всеми точками,
  где были сделаны фото поездки (не только одна точка города); выйти
  с карты можно кнопкой ×, кликом мимо неё или клавишей Esc.

## Структура файлов

- `index.html` — страница сайта
- `style.css` — оформление
- `app.js` — логика глобуса (трогать не нужно)
- `data.js` — **сюда вы вносите свои поездки**
- `photos/` — папка для ваших собственных фото (если не хотите хранить их по ссылкам)

## Пошаговая инструкция: как добавить новую поездку

### Шаг 1. Соберите фото поездки

Отберите фото, которые хотите показать на сайте (не обязательно все —
можно 5–15 штук на поездку). Оригиналы с телефона обычно весят по
несколько мегабайт каждый — сайт с такими фото будет грузиться
медленно, поэтому их нужно сжать перед публикацией.

### Шаг 2. Пришлите мне фото — самый простой способ

Напишите мне название/город поездки и путь к папке с оригиналами
(например, на диске `E:` — как со Стокгольмом и Мадейрой). Я сам:

- сожму фото, чтобы сайт грузился быстро;
- разложу их в `photos/<название-поездки>/01.jpg`, `02.jpg` и т. д.;
- если в оригиналах есть GPS-координаты (обычно есть у фото с
  телефона) — заберу их до сжатия, чтобы точки каждого фото легли на
  карту альбома (кнопка «Показать альбом на карте»);
- подготовлю для вас готовый блок для `data.js` (см. Шаг 4) —
  останется только проверить текст заметки и подписи к фото.

Чтобы не объяснять описание поездки на словах, можно положить рядом
с фото файл `Note.md` — по одной строке на каждую подсказку, в
формате `Название: значение`:

```
Описание: Текст, который увидят гости сайта в поле notes.

Музыка: Wildfire - Jessie Villa.mp3
```

- `Описание` — то, что попадёт в поле `notes` поездки;
- `Музыка` — необязательно; либо точное имя файла из общей папки
  `music/`, либо слово `случайная` — тогда при каждом запуске
  слайдшоу будет выбран случайный трек из папки.

Если вдруг захотите сжать и разложить фото сами — команда для одного
файла (замените пути на свои):

```
ffmpeg -i "исходное-фото.jpg" -vf "scale='min(1600,iw)':-2" -q:v 4 "photos/lisbon/01.jpg"
```

### Шаг 3. Найдите координаты города

Откройте Google Maps, кликните правой кнопкой по нужной точке на
карте — вверху появится всплывающее окно с координатами (`lat, lng`),
нажмите на них, чтобы скопировать.

### Шаг 4. Откройте `data.js` и добавьте блок с поездкой

Откройте файл `data.js` в любом текстовом редакторе (подойдёт
Блокнот). Внутри квадратных скобок `trips = [ ... ]` уже есть блоки
`{ ... }` для существующих поездок — скопируйте один из них целиком,
вставьте перед закрывающей `]` и замените значения на свои:

```js
{
  city: "Лиссабон",
  country: "Португалия",
  lat: 38.7223,
  lng: -9.1393,
  startDate: "2025-06-10",
  endDate: "2025-06-13",
  dateLabel: "10–13 июня 2025",
  title: "Три дня в Лиссабоне",
  notes: "Трамвай №28, пастель де ната и вид с смотровой площадки.",
  cover: "photos/lisbon/01.jpg",
  photos: [
    { url: "photos/lisbon/01.jpg", caption: "Трамвай №28", lat: 38.7223, lng: -9.1393 },
    { url: "photos/lisbon/02.jpg", caption: "" }
  ]
}
```

Важные мелочи:

- после закрывающей `}` нужна запятая `,`, если после неё в списке
  идёт ещё один блок (перед последним блоком запятая не нужна);
- `startDate`/`endDate` — формат `ГГГГ-ММ-ДД`, по ним подсвечиваются
  дни поездки в календаре справа; `dateLabel` — то, что реально видит
  посетитель сайта, можно писать как угодно ("10–13 июня 2025");
- `caption` у фото необязателен — если подписи нет, оставьте пустую
  строку `""`;
- `lat`/`lng` у фото тоже необязательны — если их указать, это фото
  появится отдельной точкой на карте альбома («Показать альбом на
  карте»); если их нет — на карте будет использована общая точка
  поездки. Когда фото присылаете мне (Шаг 2), я достаю эти координаты
  из GPS-метаданных оригиналов сам;
- `cover` — фото, которое будет обложкой альбома и точкой на глобусе;
- `music` — необязательное поле: имя файла из папки `music/` (например
  `"music/Wildfire - Jessie Villa.mp3"`) или `"random"` — тогда при
  запуске слайдшоу для этой поездки будет включаться случайный трек
  из общей папки. Если поездке нужна музыка, а Note.md прислали мне —
  я сам подставлю нужное значение сюда.

### Шаг 5. Сохраните файл и проверьте у себя

Сохраните `data.js`, затем дважды кликните на `index.html` — он
откроется в браузере. Новая поездка должна появиться на глобусе, в
календаре и в списке альбомов. Если что-то не так — переходите к
разделу «Если что-то перестало работать» ниже.

### Шаг 6. Скажите мне, что добавили

Я залью изменения на GitHub, и через одну-две минуты поездка появится
на живом сайте.

## Как посмотреть сайт локально

Просто дважды кликните на `index.html` — он откроется в браузере.
Сайт не требует установки программ или сервера.

Сайт уже опубликован на бесплатном хостинге GitHub Pages:
https://gregory-gittools.github.io/travel-globe/

появляется на этом адресе — обычно в течение одной-двух минут.

## Если что-то перестало работать

Пришлите мне скриншот страницы (и, если получится, консоль браузера —
клавиша F12, вкладка Console) — я смогу быстро найти причину и
исправить.
